# Side-Scroll Cat Defense Prototype

냥코대전쟁 느낌의 횡스크롤 타워디펜스 프로토타입입니다.

## 실행 방법

브라우저에서 `index.html`을 열거나, 아래처럼 간단한 서버를 띄워 실행하세요.

```bash
python3 -m http.server 8000
```

그 뒤 `http://localhost:8000` 접속.

## 현재 구현된 기능

- 횡스크롤 1개 라인 전투
- 골드 자동 수급
- 3종의 아군 유닛 소환
- 적 웨이브 자동 스폰 + 시간에 따른 난이도 증가
- 자동 이동/근접 공격
- 아군/적 기지 체력 및 승패 판정
- 일시정지/재시작
